# 行動規範（Code of Conduct）

[日本語](#日本語) | [English](#english)

## 日本語

StarPocket Client は、**[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** を行動規範として使います。
全文（英語）はそのページにあります。日本語の訳（2.1）: <https://www.contributor-covenant.org/ja/version/2/1/code_of_conduct/>
下は短いまとめです。まとめと全文がちがうときは、全文に従います。

### どこで守るか

GitHub（Issue・Pull Request）、公式 Discord「PocketRoles 役職部屋」、サポートのメール、そして StarPocket Games / PocketRoles の名前で人と話すところ全部です。

### みんなで守ること

- 相手を大事にします。年・性別・国・言葉・見た目・ゲームのうまさなどで、人を下に見ません。
- ちがう意見も、落ち着いて聞きます。
- まちがえたら、あやまって直します。

### してはいけないこと

- 悪口、からかい、差別、いやがらせ、しつこく追いかけること
- 性的な言葉や画像
- ほかの人の個人情報（本名・住所・フレンドコードなど）を、本人のゆるしなしに出すこと
- おどすこと、暴力をすすめること

### 困ったときは

守られていないと思ったら、メールで知らせてください。知らせてくれた人のことは秘密にします。

- あて先: `pocketroles.report+help@gmail.com`
- 件名: `[StarPocket Client] 行動規範`

### 守られなかったとき

リポジトリの持ち主（[@wakayamachannel](https://github.com/wakayamachannel)）が、何があったかを確かめてから決めます。
重さによって、1. 注意する → 2. 警告する → 3. しばらく参加できなくする → 4. ずっと参加できなくする、の順です。

## English

StarPocket Client uses the **[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
as its code of conduct. The full text is on that page; the summary above is in our own words, and where the two differ
the full text applies.

It applies on GitHub (issues, pull requests), in the official Discord server, in support mail, and anywhere people speak
in the name of StarPocket Games or PocketRoles.

Report anything that breaks it to `pocketroles.report+help@gmail.com` with the subject
`[StarPocket Client] Code of Conduct`. Reports are kept confidential. The repository owner
([@wakayamachannel](https://github.com/wakayamachannel)) looks into what happened and decides: a correction, a warning,
a temporary ban, or a permanent ban.
