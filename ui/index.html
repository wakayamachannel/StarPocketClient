    v0.5.5

    未公開・作業中

    CHANGELOG.md の v0.5.5 から要約（2026-09-22 時点）。細かい数値や手順は CHANGELOG と README にあります。

    Aegis（アンチチート）

    • 判定値を GitHub から更新 — ゲーム内 Aegis の数値とルールの強さを定義ファイル [rules] から読む。ルールの強さはゆるくする方向にしか変えられない。/ac rules で確認。
    • 定義ファイルに署名 — RSA 3072・SHA-256。署名が合うファイルだけを使い、古い版には戻さない。
    • 判定値を部屋ごとにずらす — 既定 ±10 %（0〜20 %）。公開された値ぎりぎりを狙うチート対策。
    • MOD の中のセルフチェック — ほかのプラグイン・チートの DLL・差し替え DLL・ゲームのコードの書き換えを見つけたら、ロビーを作れなくする。
    • 投票の言い当て通知 — 登録オフの部屋で、手がかりのない会議でインポスターに投票し続ける人を、ホストの画面にだけ知らせる（退出はさせない）。
    • スピードハック検知を軽く ・トレイに「脆弱ドライバーの遮断」 — 無効なら黄色の注意だけ。

    NG ワード（暴言の対策）

    • 2 回注意して 3 回目で自動退出 （この部屋へのバン付き）。ロビーでも試合中でも、登録オン・オフどちらの部屋でも。
    • 表記ゆれとローマ字も — 全角・半角、かな、間に記号を入れた書き方、ローマ字の「shine」なども。ふつうの会話に当たらないよう許可の一覧で守る。
    • /ng コマンド — 言葉の追加・削除・テスト、全部の一覧はホストの画面にだけ。一覧は GitHub の定義ファイルからも更新。
    • 安全装置 — 2 分以内に 3 人以上が当たったら、その部屋では自動退出を止めて注意だけに。

    BAN と異議申し立て

    • 部屋をまたぐ BAN — 確実な検知で退出させた人は、自分のすべての部屋で 30 日 → 180 日 → 無期限。
    • 共有 BAN — 開発者が証拠を確かめて署名した一覧だけ。公開するのは PUID のハッシュだけ。
    • 公式への通報 — 確実な検知の時は自動で（同じ人へは 30 日に 1 回、全体で 1 時間に 5 件まで）。ほかは /aegis report。
    • 証拠の記録と異議申し立て — 退出・BAN ごとに AEG-XXXXX.json。窓口は Discord のチケットとメール。
    • Aegis BAN 管理 — 作者の PC で BAN を管理するアプリ。5 秒の確認、管理人モード（提案だけ）、Windows Hello での本人確認、書き換えを見つける操作の記録。

    ロビーと通信

    • ロビーの延長の修正 — 延長の自動受け入れは v0.5.4 まで動いていなかった。サーバーの申し出を直接読んですぐ受ける。1 人なら廃村せず部屋を作り直す。
    • サーバーの近い・遠い — wire RTT 40 ms 以下で「近い」。ホストの画面に 1 行と、ログに 30 秒ごとのラグの記録。
    • 高 PING の部屋の作り直しは既定でオフに ・Discord の投稿にアイコン

    ランチャー

    • ゲームのログを残す — 開いた時と起動の直前に LogOutput-日時.log へ。7 日より前は月ごとの zip。自動では消さない。「ログのフォルダを開く」を追加。
    • 報告 zip — 過去のログ 3 回分と Aegis の証拠の記録（直近 90 日）を入れる。設定ファイルは入れない。

    修正・その他

    • 3 人の部屋でインポスターが 0 人になる不具合を修正
    • README に「Aegis と個人情報（よくある質問）」 — 調べるもの・調べないもの、送るもの、記録されるもの。
