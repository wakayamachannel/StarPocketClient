# Error codes

Look up the code you saw on your screen. It says what happened and what to do. Where you see …, a date or a reason is filled in.

## R — Rule (fix before playing)

### R-31  A tool that can be used for cheating is running

A tool that can be used for cheating (…) is running. Even if you use it for another game, you can't play while it's running.

**What to do:** Close …, then press "Check again". It also clears by itself within 30 seconds after you close it.

### R-32  A DLL with a cheat name was found

The game folder has a DLL (…) with the name of a known cheat, or with cheat, menu or inject in its name.

**What to do:** Remove … from … (delete it or move it somewhere else). If this appeared inside the game, restart the game after removing it.

### R-33  A swap-in DLL was found

Next to Among Us.exe there is a DLL (…) with a swap-in name that cheats sometimes use. Tools that change how the screen looks, such as ReShade or DXVK, can also cause this.

**What to do:** Remove …, then press "Check again". If you want to use a visual tool, read "Learn more".

### R-34  The game's code was changed

While the game was running, its code (GameAssembly.dll) was changed by something other than PocketRoles and BepInEx.

**What to do:** Close tools that attach to the game (trainers, cheat tools and so on) and restart the game. If it keeps happening, make a report zip and contact us.

### R-41  The PocketRoles file has changed

The contents of PocketRoles.dll have changed since it was installed (the version number is still v…). Sometimes the download was just damaged.

**What to do:** The Play button has turned into "Repair". Press it to reinstall PocketRoles; when it finishes, it turns back into "Play". If you built it yourself, use it in developer mode.

### R-42  Another plugin is installed

BepInEx's plugins folder has a plugin other than PocketRoles (…).

**What to do:** Remove … from the plugins folder. To play other mods, use a separate Among Us folder.

### R-43  Something is in the patchers folder

BepInEx's patchers folder has a file (…). With PocketRoles, this folder stays empty.

**What to do:** Remove … from the patchers folder.

### R-44  BepInEx's start-up part is different

winhttp.dll in the game folder is not the one from the set BepInEx version (6.0.0-be.735).

**What to do:** The Client's Play button has turned into "Repair". Press it to reinstall BepInEx; when it finishes, it turns back into "Play". If this appeared inside the game, repair it and then restart the game.

### R-45  Windows protection is weakened

Windows is running in test mode or debug mode, or with integrity checks turned off (…). Some people turn this on themselves for development. It is not proof of cheating.

**What to do:** Turn it off using the steps in "Learn more", then restart the PC. If you're not sure, ask a family member to help.

## J — Joining a room

### J-21  Removed for an impossible action

An action that normal Among Us cannot do (…) was found, so you were removed from the room and restricted on this room's host PC. If a match was in progress, it may have been ended for everyone.

**What to do:** If you think it's a mistake, you can appeal. Contact us with your in-game name, the date and time, the room code and your friend code (please don't write your real name).

### J-22  Removed after it happened twice

An impossible movement or action (…) was found twice, at different moments.

**What to do:** This can also happen when the connection is unstable. If you think it's a mistake, contact us.

### J-51  Removed for hurtful words

Hurtful words were found in the chat 3 times.

**What to do:** If you think it's a mistake (for example, the word meant something else), contact us with the word and the date and time. We will fix the word list.

### J-52  Removed for flooding the chat

Chat flooding faster than a person can type was found twice.

**What to do:** Check that you are not using a tool that sends messages automatically. If you think it's a mistake, contact us.

### J-61  The host removed you

The host of that room decided to remove you or stop you from joining.

**What to do:** Only the host can undo what the host decided. Please ask the host.

### J-81  You're restricted on this host's PC

You're restricted from joining on this host's PC (decided by Aegis or by the host). You'll be removed soon.

**What to do:** Don't rejoin the same room (you won't be able to join it again). If you think it's a mistake, contact us. If the host decided it, please ask the host.

### J-91  You have a shared ban

Because of a shared ban the author decided after looking at the evidence, you can't join PocketRoles rooms that use shared bans. It is lifted automatically when it ends.

**What to do:** If you think it's a mistake, please appeal. Once lifted, you can join from the next time each host starts the game.

## B — Ban (an account with a shared ban)

### B-91  Your access to this game is restricted

This Among Us account has a shared ban that the author decided after looking at the evidence (…; reason: …). While it lasts, you can't create online rooms with PocketRoles, and you can't join PocketRoles rooms that use shared bans. This isn't a ban of your Among Us account.

**What to do:** If you think it's a mistake, appeal and include "Your code" shown on the screen and your in-game name. It's lifted automatically when it ends or when an appeal is accepted. Plain Among Us from Steam works as usual.

## S — Service

### S-11  We're not accepting your shared-ban requests

Because something did not follow the rules, or your reports were found to be wrong on appeal 3 times within 30 days, we won't accept shared-ban requests from you until …. Reason: …

**What to do:** If you disagree, you can appeal through support. Restrictions in your own room still work as before.

### S-12  Your room can't be listed

This host's key can't be used for the room list until …. Reason: …. You can still play with PocketRoles.

**What to do:** Friends can still join if you give them the room code. If you disagree, you can appeal through support.

### S-13  Part of Discord is unavailable

On the Discord server, … is stopped (until …). Reason: …

**What to do:** Please appeal through the email contact.

### S-14  Part of the support chat is unavailable

Until …, you can't use the support chat's …. Reason: …

**What to do:** For urgent matters, or to ask us to show or delete your information, please use email.

### S-15  This account is suspended

This account's features are stopped until …. Reason: …

**What to do:** You can still contact support without an account. You can still ask us to show or delete your information.

### S-16  This service isn't available to you right now

You can't use … until …. Reason: …

**What to do:** If you disagree, you can appeal through support.

## P — Preparation

### P-01  Steam isn't running

Steam needs to be running to start Among Us.

**What to do:** Press "Start Steam". When Steam opens, Play comes back by itself.

### P-02  Among Us wasn't found

Among Us wasn't found in Steam on this PC.

**What to do:** Press "Install with Steam" to install Among Us. If it's somewhere else, press "Choose folder".

### P-03  Among Us is already running

Among Us is already running. You can't start two at once.

**What to do:** Press "Switch to the game".

### P-11  Not installed yet

PocketRoles isn't on this PC yet.

**What to do:** Press "Install". It copies about 1 GB and downloads about 40 MB.

### P-12  A step stopped partway

An install or update step (…) failed partway.

**What to do:** Press "Continue". Finished steps are skipped. If it keeps failing, make a report zip and contact us.

### P-13  The Steam version was updated

Among Us on Steam was updated. The mod copy must be updated before you can go online.

**What to do:** Press "Update and play".

### P-14  BepInEx wasn't found

The part that runs the mod (BepInEx) is missing or incomplete.

**What to do:** Press "Repair".

### P-21  The new Among Us isn't supported yet

Among Us is now …. PocketRoles only supports … so far. If you start it like this, the mod won't run.

**What to do:** Please wait for a supported version. When it's out, we'll tell you in the news and with the "Update" button.

### P-22  An update is needed

This PocketRoles (v…) is too old to use. v… or later is needed.

**What to do:** Press "Update". It takes a few seconds.

### P-23  A new version is available

A new version of PocketRoles (v…) is available.

**What to do:** Press "Update" to install it. You can also keep playing with the current version.

### P-24  PocketRoles couldn't load

When the game started, PocketRoles failed to get ready. The mod won't run this time.

**What to do:** Close the game and press the Client's Play button (it has turned into "Repair"). It reinstalls, then turns back into "Play". If it still doesn't work, make a report zip and contact us.

### P-31  Please review the Terms and Privacy Policy

The first time you use it, or when the Terms of Use or Privacy Policy change in an important way, you need to read them and agree. Without agreeing, you can't use the official Client (the PocketRoles source stays GPL-3.0, and anyone can build and modify it).

**What to do:** Read the screen, tick the box and press "Agree". If you are under 18, read it together with a parent or guardian.

## N — Network

### N-01  Couldn't get the news

You're offline, or the news (status.json) couldn't be received. The last news received is used.

**What to do:** You can play offline. It updates by itself once you're connected

### N-02  Couldn't get the definitions file

The Aegis definitions file couldn't be received. The last one received is used.

**What to do:** You can keep playing. It tries again at the next start

### N-03  Please wait a little

Too many requests were sent to GitHub, so it can't be used for a while (a rate limit).

**What to do:** Wait about an hour and press it again

### N-04  The download wasn't found

A file that's needed wasn't found where it's published.

**What to do:** Try again a bit later. If it keeps happening, contact us

### N-05  The download is damaged

The downloaded file doesn't match what it should be. For safety, it isn't used.

**What to do:** Try again. If it keeps happening, contact us

### N-06  The news signature doesn't match

The signature of the news received doesn't match, so it isn't used. The last news is used instead.

**What to do:** You can keep playing. If it keeps happening, contact us

### N-11  Can't reach the support chat

The support server is down (a power cut, maintenance and so on).

**What to do:** Please use email (pocketroles.report+help@gmail.com) or a Discord ticket

### N-12  The bot check didn't work

The bot check (Cloudflare Turnstile) didn't finish.

**What to do:** Reload the page or try another browser

## A — Aegis notice

### A-01  The definitions signature doesn't match

The signature of the definitions file received doesn't match, so it isn't used. The previous file or the built-in values are used. Shared bans can't be used until a file with a matching signature is available.

**What to do:** It usually fixes itself at the next start. If it keeps happening, contact us

### A-02  Aegis detection is off

Aegis detection is turned off in settings.

**What to do:** To protect your room, turn it on in settings

### A-03  Secure Boot is off

Secure Boot is off on this PC. You can still play.

**What to do:** If you're not sure, it's fine to leave it

### A-04  No TPM found

No TPM was found on this PC. You can still play.

**What to do:** It's fine to leave it

### A-05  The driver blocklist is off

Windows' vulnerable driver blocklist is off. You can still play.

**What to do:** "Learn more" shows how to turn it on

### A-06  An unsigned DLL was loaded

A DLL with no signature (or a signature that doesn't match) (…) is loaded into the game. This alone doesn't stop anything.

**What to do:** If you don't recognise it, make a report zip and contact us

### A-07  A driver to be careful about is loaded

A driver that is sometimes used by cheats (…) is running. Ordinary tools, such as fan controllers, use it too. This alone doesn't stop anything.

**What to do:** If it's a tool you don't use, consider uninstalling it

### A-08  Two copies of PocketRoles

There are two copies of PocketRoles in the plugins folder. Only one runs.

**What to do:** Remove the older one

### A-09  Aegis couldn't finish checking

An error happened inside Aegis, or it took too long. Play isn't stopped.

**What to do:** Check again, or if it keeps happening, make a report zip and contact us
